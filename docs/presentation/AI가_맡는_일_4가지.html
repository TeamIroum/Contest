촬영 단계 자동 마스킹

개인정보 보호 업무 최소화
앱서버
AI가 없으면점검단이 찍은 수천 장의 사진을 담당자가 한 장씩 보고 얼굴을 가려야 함

어떻게 작동하나

  • 앱이 휴대폰 안에서 얼굴과 차량 번호판을 찾아 가린 뒤 전송
  • 가리지 않은 원본은 휴대폰 밖으로 나가지 않음
  • 번호판을 못 찾은 차량은 차 전체를 뭉개서 가림
  • 서버는 저장 전에 가림 상태를 한 번 더 확인하고, 혹시 남은 부분이 있으면 저장·AI 판독 전에 가림
  • 이미 학습된 공개 검출 모델을 써서 별도 학습 없이 바로 적용

무엇이 줄어드나

  • 담당자가 사진마다 모자이크할 필요 없음
  • 일부 사진만 골라 가림 상태를 점검
  • 개인정보 보호에 드는 시간 대폭 감소
2

시설·이상 자동 판독

담당 부서 자동 배정
서버
AI가 없으면무엇이 찍혔는지 사람이 분류해 담당 부서를 찾아야 함

어떻게 작동하나

  • 점검 대상 5종 중 어떤 시설인지 판단
    보도블록빗물받이벤치안전펜스운동기구
  • 들뜸·파손·이탈 같은 이상과 위험도까지 판단
  • 이미 학습된 AI에 우리 기준표(위험도 0~3)를 적용해 판단, 시설 사진으로 따로 학습하지 않음

무엇이 줄어드나

  • 정해진 규칙대로 담당 부서 지정
    보도블록 들뜸 → 도로 담당벤치 좌판 파손 → 공원 담당
  • AI가 확신하지 못한 사진만 담당자가 확인
3

전후 사진 AI 비교

수리 확인과 변화 감시 자동화
앱서버
AI가 없으면지난번 사진과 비교해 고쳐졌는지 사람이 대조해야 함

어떻게 작동하나

  • 같은 장소인지 먼저 확인한 뒤, 고쳐졌는지·나빠졌는지 판단
  • 재촬영 때 이전 사진을 흐리게 겹쳐 보여 같은 위치·각도로 촬영

무엇이 줄어드나

  • "처리 완료로 보고됐지만 그대로"를 사진 대조 없이 파악
  • 고쳐지지 않은 곳은 근거 사진과 함께 재요청
  • 나빠지는 곳은 등급을 올려 먼저 처리
4

활동 기록과 주간 보고 자동 정리

담당자는 확인만
서버
AI가 없으면활동 기록이 종이나 사진 더미로 남음

어떻게 작동하나

  • 촬영 시각, 점검한 시설 수, 판독 결과가 자동으로 쌓임
  • 시설별 이력과 참여자별 활동 기록으로 관리
  • 이동 경로는 기록하지 않음

무엇이 줄어드나

  • 참여자 활동 실적 자료 자동 생성
  • 주간 점검 보고서 자동 생성: 긴급·주의 건수, 수리 확인 결과, 우선 처리 목록
  • 문장은 AI가 쓰되, 숫자는 시스템 계산값만 사용

AI 학습은 어떻게 하나

모두 이미 학습된 AI를 쓰고, 우리 데이터로는 학습 대신 평가를 합니다.

별도 학습 없음
