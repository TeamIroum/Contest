# 관리자 웹

기준 문서: [기능정의서 6·7·8절](../../docs/기능정의서.md), [API 명세서 8~11절](../../docs/API_명세서.md)

공모전 시연에서는 관리자 계정 하나에 세 역할(활동 담당자, 시설 담당자, 사업 총괄)을 부여합니다. 역할마다 메뉴를 나눠 두면 실제 운영에서 계정을 나눌 때 화면을 고치지 않아도 됩니다.

| 역할 | 주요 화면 | 기능정의서 ID |
|---|---|---|
| 활동 담당자 | 참여자·조·코스·순회 배정, 출석·출발·복귀 확인, 활동 현황 | `ACT-*` |
| 시설 담당자 | 통합 검토 목록, 사진·AI 근거 조회, 판정, 사건·보수·수리 확인, 개인정보 사진 검토 | `FAC-*` |
| 사업 총괄 | 기관·역할 관리, 주간 집계·보고, 알림, 감사 이력 | `OPS-*` |

## 꼭 지킬 것

- AI 결과는 제안입니다. 수리 종결·재보수·사건 연결은 담당자가 확정합니다. (`FAC-05`, `FAC-09`)
- 승인되지 않았거나 보류된 사진은 보여주지 않습니다. AI 서버의 사진 주소를 직접 쓰지 않습니다. (`FAC-03`)
- 판정 화면에는 판단 근거로 본 AI 결과 스냅샷을 함께 남깁니다.
