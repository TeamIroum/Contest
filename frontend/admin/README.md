# 관리자 웹

기준 문서: [기능정의서 6·7·8절](../../docs/기능정의서.md), [API 명세서 8~11절](../../docs/API_명세서.md)

공모전 시연에서는 관리자 계정 하나에 세 역할(활동 담당자, 시설 담당자, 사업 총괄)을 부여합니다. 역할마다 메뉴를 나눠 두면 실제 운영에서 계정을 나눌 때 화면을 고치지 않아도 됩니다.

| 역할 | 주요 화면 | 기능정의서 ID |
|---|---|---|
| 활동 담당자 | 참여자·조·코스·순회 배정, 출석·출발·복귀 확인, 활동 현황 | `ACT-*` |
| 시설 담당자 | 통합 검토 목록, 사진·AI 근거 조회, 판정, 사건·보수·수리 확인, 개인정보 사진 검토 | `FAC-*` |
| 사업 총괄 | 기관·역할 관리, 주간 집계·보고, 알림, 감사 이력 | `OPS-*` |

## 꼭 지킬 것

- AI 결과는 제안입니다. 수리 종결·재보수·사건 연결은 담당자가 확정합니다. (`FAC-05`, `FAC-09`)
- 승인되지 않았거나 보류된 사진은 보여주지 않습니다. AI 서버의 사진 주소를 직접 쓰지 않습니다. (`FAC-03`)
- 판정 화면에는 판단 근거로 본 AI 결과 스냅샷을 함께 남깁니다.

## 지금 들어 있는 것 (시연용 프로토타입)

실행 방법은 [frontend/README.md](../README.md)에 있습니다. 시연 로그인은 로그인 화면 아래 "시연 관리자"를 누르고 "로그인"입니다. 이 계정에는 활동 담당자·시설 담당자·사업 총괄·시스템 관리자 네 역할이 모두 있습니다.

| 메뉴 | 파일 | 내용 |
|---|---|---|
| 오늘 활동 현황 | `src/Activity.tsx` | 조별 출석 확인·대리 출석·출발 확인·복귀 확인·시각 정정·활동 없이 해산·후속 기록. 숫자 카드를 누르면 해당 조만 걸러 보고, 할 일이 있는 조는 "지금 할 일"로 위에 모음 |
| 조 편성 · 코스·순회 배정 · 참여자 계정 | `src/Activity.tsx` | 조원 2~3명 편성, 날짜별 순회 일정, 재점검 요청을 순회에 배정 |
| 검토 목록 | `src/Review.tsx` | 올라온 이유별 검토, AI 판독 결과(등급 없음), 분류 정정, 판정(이상 확인 / 이상 없음(담당자 확인) / 추가 확인), 기존 문제 연결 |
| 사건·보수 | `src/Issues.tsx` | 접수 → 보수 요청 → 보수 중 → 확인 대기 → 종결, 재점검 사진으로 수리 확인 |
| 통계·보고 | `src/Stats.tsx`, `src/xlsx.ts` | 기간별 집계, 보고 문장, 엑셀 5개 시트(요약·점검 내역·부서별 집계·수리 확인 내역·점검원 활동) |
| 공무원 계정 | `src/Admins.tsx` | 계정 발급·역할·비밀번호 초기화·잠금 해제 (시스템 관리자) |

공용 화면 조각은 `src/ui.tsx`, 예시 데이터는 `src/data.ts`, 시연 시계는 `src/util.ts`에 있습니다.

색 규칙: 파랑 = 진행 중, 호박 = 담당자가 처리할 일, 초록 = 끝남·정상, 회색 = 종류·정보, 빨강 = 잠김·오류.
