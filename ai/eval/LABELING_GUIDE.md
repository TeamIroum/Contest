# 테스트셋 라벨 작성 기준

AI 판독이 얼마나 맞는지 재려면 사람이 정한 정답이 있어야 합니다. 이 문서는 그 정답을 팀원 누가 달아도 같게 나오도록 하는 기준입니다.

## 1. 사진 모으기

- 대상: 점검 대상 5종(보도블록, 빗물받이, 벤치, 안전펜스, 운동기구)
- 규모: 시설당 50장 이상, 총 200장 이상. 정상 사진과 문제 있는 사진을 대략 반반으로
- 정도 3(긴급)에 해당하는 사진을 시설마다 최소 5장은 확보합니다. 긴급 재현율을 재려면 꼭 필요합니다
- 일부러 나쁜 사진도 섞습니다: 흐린 사진, 어두운 사진, 시설이 잘린 사진 각 10장 정도
- 촬영 안전: 차도에 들어가지 않고, 시설을 만지지 않습니다
- 개인정보: 사람 얼굴과 차량 번호판은 피해서 찍습니다
- 사진은 `eval/photos/` 아래에 두고, 파일 이름은 `시설_번호.jpg` (예: `sidewalk_014.jpg`)

수리 확인용 전후 사진 쌍도 따로 모읍니다. 낙엽이 쌓인 빗물받이를 청소 전후로 찍는 것처럼 실제로 상태가 바뀌는 장면을 노립니다. 같은 자리·같은 각도로 찍은 쌍과, 일부러 옆 시설을 찍은 쌍(정답: different_place)을 함께 만듭니다. 목표는 30쌍 이상입니다.

## 2. labels.csv 형식

`eval/labels_sample.csv`와 같은 열을 씁니다.

| 열 | 값 |
|---|---|
| `photo_id` | 고유 ID |
| `image_path` | CSV 파일 기준 상대 경로 |
| `facility_type` | `sidewalk`, `drain`, `bench`, `fence`, `exercise` (`taxonomy.json` 영문 키) |
| `issue_type` | 가장 심한 문제 하나의 영문 키. 문제 없으면 비움 |
| `severity` | 0~3. `taxonomy.json`의 `severity_guide` 문장 기준 |
| `quality_ok` | 판독할 만한 사진이면 1, 다시 찍어야 할 사진이면 0 |
| `location_tags` | 실제 위치 조건. 세미콜론 구분 (`school_route;roadside`) |
| `capture_hour` | 촬영 시각 0~23 |
| `note` | 애매했던 점 메모 |

전후 쌍은 `eval/pairs_sample.csv` 형식을 따릅니다. `expected`에는 `fixed`, `not_fixed`, `different_place`(repair 모드), `worse`, `same`, `better`(change 모드) 중 하나를 씁니다.

## 3. 정도 판단 요령

- 기준표 문장과 가장 가까운 단계를 고릅니다. "내 가족이 지금 여기를 걷는다면 다칠 수 있나"가 3의 기준입니다
- 위치는 정도에 넣지 않습니다. 통학로든 아니든 같은 상태면 같은 정도를 매기고, 위치는 `location_tags`에 따로 적습니다
- 벤치·운동기구는 부품이 빠졌으면 정도가 낮아 보여도 최소 '주의' 등급이 됩니다(규칙표). 라벨에는 보이는 정도 그대로 적습니다

## 4. 사람끼리 일치율 재기

전체 사진 중 40장 정도를 팀원 두 명이 서로 보지 않고 따로 라벨링합니다. 시설 종류, 정도, 재촬영 여부가 몇 %나 일치하는지 기록합니다. 의견이 갈린 사진은 함께 보며 기준표 문장을 고치고, 고친 내용은 `taxonomy.json`에 반영합니다.

이 수치가 있으면 AI 결과를 "사람끼리도 이 정도 일치하는데 AI는 이 정도"라고 설명할 수 있습니다.
