양주 장바구니

“영수증 한 장이 곧 물가 센서.” 시민이 영수증·매대 가격표·전단을 사진으로 올리면 AI가 품목·가격을 읽어 동네·마트별 실시간 물가를 지도로 보여주는 모바일 앱. 정부 통계의 느린 집계 대신, 시민이 매일 만드는 구매 데이터를 모아 ‘지금 가장 싼 곳’을 알려주고 양주사랑상품권으로 참여를 보상합니다.

전단 · 예고가 매대 · 현재가 영수증 · 실구매가 AI OCR + 크라우드소싱

03

입력 우선순위 · 출처 표기

AI가 올린 사진을 자동 분류하고, 가장 신뢰도 높은 값을 노출

표시 규칙

품목 × 매장별 ‘최선값’ 1개

각 가격에 출처 배지와 갱신 시각을 함께 표기합니다.

🧾 영수증1순위 · 실구매가
🏷️ 가격표2순위 · 매대 표시가 (영수증 없을 때)
📄 전단예고가 · 유효기간 관리

보정 규칙

최신성 역전 · 의미 구분

  • 최신성 역전 — 2주 전 영수증보다 2시간 전 가격표가 더 정확할 수 있다. 상위 출처가 오래되면 최신 하위 출처에 양보.
  • 의미 라벨 — 영수증 = 실제 낸 값(할인 반영) / 가격표 = 매대 표시가. 혼동 없게 구분 표기.
  • 교차검증 — 단독 1건은 ‘미확정’, 2건 이상 일치 시 ‘확정’ 배지.
04

핵심 기능

업로드 → OCR → 지도 한 줄기가 실제로 도는 앱

홈

물가지도

위치 기준 마트별 가격 핀 + 주간 ‘장바구니 지수’. 최저가 초록, 특가 빨강.

올리기

현장 모드

사진을 올리면 영수증/가격표/전단 자동 분류·인식, 개인정보 즉시 마스킹. 매대 가격표 연속 스캔.

비교

품목 줄세우기

한 품목을 동네 마트별 최저가로 정렬 + 6주 추이로 다음 특가 예측.

마트 상세

가격 3종 분리

전단 특가·매대 현재가·영수증 실구매가를 분리 표시, 만료 시 자동 이력화.

05

AI 처리 파이프라인

단순 OCR을 넘어 ‘판단·예측’까지

수집
시민이 영수증·가격표·전단 촬영 업로드 (현장 실시간 카메라 우선).
입력 자동분류
올린 사진을 영수증 / 가격표 / 전단으로 판별해 각기 다른 파이프라인으로 분기.
인식 · 정규화
OCR+LLM으로 제각각 표기(‘農心신라면멀티5’)를 표준명(‘신라면 5개입’)으로. 바코드로 상품 특정, 단위가격(원/100g) 환산해 공정 비교. 긴 영수증은 분할 촬영 병합 후 소계·할인·결제정보는 걸러 품목만 추출.
검증 · 보안
개인정보 즉시 마스킹 + 복수 제보 교차검증으로 허위·이상치 제거. GPS·EXIF·사업자번호 대조.
집계 · 지도화
품목×매장 최선값 산출 → 생활권 물가 히트맵·장바구니 지수.
예측 · 추천
전단 할인 이력 학습으로 품목별 ‘다음 특가 예상일’ 산출, 최저가 장보기 추천.

08

고도화 로드맵

‘물가 앱’에서 ‘지역 물가 플랫폼’으로

A · AI 판단

읽기 → 예측·추천

  • 단위 환산 최저가 — 용량 다른 상품도 원/100g로 공정 비교
  • 특가 예측 캘린더 — 품목별 ‘다음 할인 D-day’
  • AI 장보기 에이전트 — “2만원 3일치 식단” → 최저가 쇼핑리스트
  • 재구매 주기 예측 — 떨어질 때쯤 특가 알림

B · 공공 연계 (가산점)

지역 선순환

  • 양주사랑상품권 연계 — 최저가+가맹점 우선 추천
  • 행정 물가 대시보드 — 생활권 히트맵을 정책 근거로 제공
  • 취약계층·전통시장 — 물가 부담 지도, 특가 노출
  • 공공 API 개방 — 타 지자체 복제 가능

C · 데이터 신뢰

크라우드 품질 관리

  • 사업자번호·GPS·시간 교차검증, 이상치 자동 제거
  • 기여 랭킹·배지·상품권 리워드로 데이터 밀도 확보

D · 기술 완성도

비용·프라이버시

  • 하이브리드 OCR 라우팅(Flash↔Upstage/CLOVA)
  • 업로드 전 엣지 마스킹, 상품 매칭 벡터DB/RAG
